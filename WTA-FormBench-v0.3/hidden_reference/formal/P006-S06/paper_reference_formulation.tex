\section*{Static soft-kill stage and dynamic wrapper reference}
For each stage, use binary assignments \(x_{cwm}\) across six defensive weapon types, weapons and missiles. Minimize weighted residual missile survival using distance-adjusted intercept and defeat probabilities. The static reference includes range eligibility, jammer horizontal and vertical coverage, guidance compatibility, non-jammer one-target-at-a-time use, at-least-one eligible defense, over-assignment control and binary domains. The dynamic wrapper repeats the static stage after computing the stage interval, updating missile coordinates, carrying forward surviving missiles and adding new missiles.
