# Scenario

Formulate the multi-stage assignment model with nonnegative integer weapon counts and binary target-stage selections. Minimize total weapon cost across stages, categories and targets. Compute each target's accumulated destruction as one minus the product of assigned weapons' failure probabilities. Require thresholds, inventory limits, stage availability, assignment-selection consistency, at least one weapon when selected, and only one selected stage per target.

Scale: P005-S05 uses the formal split and disclosure level L3. The accompanying JSON file provides all public instance data needed for this sample.
