Formulate the per-frame dynamic mixed-integer model. Use binary UAV-radar assignment variables and continuous UAV-radar bandwidth allocation variables. Maximize total utility over radars, where utility is the suppressive jamming reward induced by bandwidth-adjusted jamming-to-signal effects minus a cost proportional to the number of UAVs assigned to that radar. Enforce that each UAV selects at most one radar, assignments respect feasibility, bandwidth is positive only for assigned UAV-radar pairs, and the sum of assigned UAV bandwidths fully covers each suppressed radar's working bandwidth. Treat surrogate prediction, memory storage, genetic search and differential evolution as solution mechanisms rather than model constraints. This controlled variant changes only the declared resource or candidate restriction field from the base public data.
