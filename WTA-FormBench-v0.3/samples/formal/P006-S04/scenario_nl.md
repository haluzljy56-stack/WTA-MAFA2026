# Scenario

Formulate the static stage model and the dynamic staged wrapper. In each stage, choose binary weapon-type, weapon and missile assignments to minimize weighted residual missile survival after distance-adjusted interception and defeat probabilities. Enforce one-at-a-time use for non-jammers, at least one eligible defense per considered missile, range bounds, jammer horizontal and vertical coverage, guidance compatibility, over-assignment prevention and binary domains. The wrapper computes stage intervals, updates missile coordinates, removes destroyed or hit missiles, allows new missiles and resolves with updated data.

Scale: P006-S04 uses the formal split and disclosure level L3. The accompanying JSON file provides all public instance data needed for this sample.
