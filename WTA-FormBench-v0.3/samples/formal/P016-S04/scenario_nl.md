Formulate both the original binary WTA and the source-supported continuous convex relaxation. The original model uses binary weapon-target assignment variables and minimizes the sum over targets of target value times the product of assignment-dependent failure terms. The relaxation replaces binary assignments with continuous effort variables, uses the convex objective formed by raising each failure probability to the assigned effort, and enforces effort bounds and per-weapon effort budgets. Treat asynchronous primal-dual communication, delayed updates and convergence proofs as solver/implementation mechanisms, not as additional assignment constraints.
