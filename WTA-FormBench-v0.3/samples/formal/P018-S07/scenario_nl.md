Formulate the WTA model with target-launcher-time binary decisions. Compute relative distance from launcher position to the target's predicted intercept point, compute heading error from launcher orientation and the heading vector to that intercept point, and use the distance and heading-error probability functions to define kill probability. Maximize the sum over targets of one minus the product of failure probabilities across all assigned launcher-time engagements. Enforce one target per launcher per slot, target assignment upper bounds, launcher interceptor capacity, firing delay and feasible firing-slot constraints. If the rotation strategy is activated, add rotation/realignment time and maximum rotation-angle constraints. Treat clustering-based initial orientation and greedy solution algorithms as algorithms, not as coverage constraints. This case changes only feasible firing slots.
