Formulate the ADRAP model with binary missile-vehicle assignment decisions, binary radar tracking decisions and interception-time variables for each target attempt. Maximize the expected intercepted value minus operational cost in unsaturated scenarios, and maximize expected intercepted value alone in saturated scenarios. Expected value is computed from target values and the success probabilities of scheduled interception attempts. Enforce one missile vehicle and one radar per interception attempt, consistency between missile and radar assignment, radar tracking timing, radar detection feasibility, radar channel capacity over time, missile vehicle load limits, consecutive-interception time spacing, missile engagement feasibility and valid variable domains. This controlled variant changes only the declared pressure field from the base public data.
