# Scenario

Build a multi-stage weapon-target assignment model. Decide how many weapons of each category to assign to each target in each stage, and whether a target is selected in that stage. Weapon categories have stage-specific inventories and unit costs. Target destruction accumulates from independent attack effects. Respect inventories, target-stage availability, positive-assignment linking and one selected stage per target.

Scale: P005-S02 uses the dev split and disclosure level L2. The accompanying JSON file provides all public instance data needed for this sample.
