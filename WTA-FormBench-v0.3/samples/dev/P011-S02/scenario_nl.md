Build an adversarial missile-target assignment model. Each missile has cost and destructive payload; each target has value and health. The kill probability of a missile against a target depends on the missile payload relative to the target health. Multiple surviving missiles assigned to the same target combine through independent attack effects. Penetration probabilities model whether missiles survive adversarial interception. Each missile must be allocated to exactly one target. If the scenario asks for cost awareness, combat effectiveness and missile cost should be represented as separate objectives.
