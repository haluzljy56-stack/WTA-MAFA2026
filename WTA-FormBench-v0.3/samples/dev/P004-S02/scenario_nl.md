# Scenario

Build a dynamic naval air-defense planning model. Defensive fire channels can start feasible engagements at feasible times. Engagements may require radar illumination and occupy weapon or radar resources over setup and engagement intervals. Ships can turn only within rate limits, firing directions may be blocked by relative-bearing blind sectors, and a platform must survive long enough to complete the engagement. Previously committed engagements can be fixed during an update.

Scale: P004-S02 uses the dev split and disclosure level L2. The accompanying JSON file provides all public instance data needed for this sample.
